# 对话、服务咨询与业务办理
系统有普通聊天、服务咨询、业务办理三条路径。普通聊天由大模型生成回复，可以讨论学习、兴趣和日常安排；它没有数据库查询或预约提交权限，不查询实时天气、新闻或航班。

服务咨询先检索本地项目说明，再让模型依据资料回答，并展示来源编号与原文。资料没有答案时会说明依据不足；引用格式和原文匹配校验不能保证每一句模型解释都正确，可展开依据核对。

号源、科室位置、预约记录等动态数据继续从虚构演示数据库查询。选择号源只生成待确认信息；预约提交仍需要明确确认。有待确认或提交结果未知的任务时，请先确认、取消或核实，之后再切换话题。取消本次操作不能撤销已提交的模拟预约。

普通聊天保留同一会话内有限的聊天上下文，不代表永久记忆。聊天与业务分别保存近期历史，普通聊天请求不自动携带之前的健康记录、预约数据或确认令牌。用户直接输入的聊天内容仍可能被发送给所配置的模型服务商，不应输入真实健康数据、密钥或不愿分享的信息。

模型超时或输出校验失败时，普通聊天明确显示暂不可用；服务咨询可以显示相关原文；业务工具查询的部分结果保留并标明未全部完成。系统不声称操作已成功，除非受控业务接口已经确认结果。
