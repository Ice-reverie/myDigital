# 关节修正复核 · V2

## 修正内容

- 保留角色的网格、材质、骨架和权重，仅修改新增的两个 Action。
- 改用较自然的斜向上掌心，将翻掌旋转分配到上臂和前臂，减少肘部袖管的集中扭转。
- 调整共同叠手姿态、肘部位置和腕部方向；限制腕部折角，保持两手轻搭。
- 放缓翻掌和回收，调整右手运动路径及间隙。

## 视觉复核

同一机位、原始材质的修正前后对比见 [对比页](../joint_compare.html)。本轮实际检查了：

- `Idle_Doctor` F1：顶部和侧面近景的手掌搭接、腕部衔接，以及后侧袖管。
- `Explain_Gentle` F62：抬手翻掌中间阶段的右肘和肩部。
- `Explain_Gentle` F108、F210：两次主要手势的后侧肘部。原先袖管明显塌陷并露出皮肤的位置，当前检查图中已恢复连续。

目录保留原材质与中性材质检查图，详细帧数据见 `measurements.json`。未在这些视角和姿态发现原先的明显扭曲；不将有限视图检查等同于所有角度均无瑕疵。

## 保持的约束

- `Idle_Doctor`：30 fps，8 秒，播放 F1–240，F241 闭合。
- `Explain_Gentle`：30 fps，10 秒，播放 F1–300，F301 闭合。

- 两个 VRMA 在独立 Blender 进程中回导验证通过，误差见 `../vrma_roundtrip.json`。
