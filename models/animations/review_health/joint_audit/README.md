# 关节审查结果

结论：当前审核版存在关节姿态和蒙皮变形问题，建议修正后再接入。此次没有修改或重新导出两个 Action。

## 已确认的问题

### 1. 讲解时右肘后侧袖管塌陷、局部露肤（defect，优先修复）

- 在 `Explain_Gentle` F108（3.57 秒）与 F210（6.97 秒）的后侧原材质近景中，可以看到右肘袖管的折叠凹陷和露出的皮肤。灰色材质近景也显示相同的几何折叠。
- `J_Bip_R_LowerArm` 的局部轴向旋转最高约 146.81°，基础姿态约 -6.4°。该骨架没有额外的前臂扭转辅助骨，旋转集中在现有前臂骨及其权重过渡处。
- 临时诊断：F108 保持肘、腕位置和手掌世界方向，将前臂轴转从约 146.8° 降至 20°。肘周抽样衣料边的最大拉伸比从 2.14 倍降至 1.49 倍，被压缩到原长一半以下的边从 3 条降至 0 条。这个实验仅用于定位成因，已经恢复，没有写入 Action；它也不是可直接使用的修复姿势。
- 证据：`Explain_Gentle_F108_arm_back_original.png`、`Explain_Gentle_F108_arm_back_clay.png`、`Explain_Gentle_F210_arm_back_original.png`、`elbow_deformation.json`。
- 建议：联合调整上臂方向、肘位与翻掌方向，使旋转合理分配，再检查实际袖子蒙皮。不要仅把旋转从前臂转移到手腕。

### 2. 两个动作共有的基础姿态折腕过大（defect）

- 以肘→腕与腕→中指根部两条三维轴线测量：待机左腕约 66.1°，右腕约 68.0°；讲解右腕在 F48 达到约 71.44°。
- 顶视图可以看到手掌明显横折向身体内侧，前臂与手的衔接不符合此次“舒适、自然、长时间接待”的动作目标。该测量是模型轴线夹角，不作为人体医学活动范围判断。
- 左手在讲解全程保持这一偏大的弯折，因此问题同时影响待机和讲解。
- 证据：`Idle_Doctor_F001_wrist_top_original.png`、`Idle_Doctor_F001_wrist_side_original.png`、`Explain_Gentle_F050_wrist_side_original.png`、`measurements.json`。
- 建议：先调整双肘和腕部空间位置，再确定叠手方向，让手掌与前臂衔接更顺，保持轻搭关系。

## 次要观察

- 讲解回收时右前臂在 F246 的单帧世界旋转变化约 4.16°（30 fps 下约 125°/秒），相对目标的舒缓气质偏快，建议随扭转修复一起放缓。
- 所有整数帧检查中未见 180° 突翻；头颈、膝踝在本次正面/后侧和全帧运动检查中没有发现同类明显异常。腿部姿态在两个动作中固定。
- 肩部和衣料仍存在原模型褶皱与低面数轮廓，不能仅凭这些轮廓认定关节脱位。
